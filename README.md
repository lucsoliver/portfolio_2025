# Portfólio

Portfolio pessoal desenvolvido com React, TypeScript e Vite.

## Stack

- React 19
- TypeScript
- Vite
- React Router
- i18next / react-i18next
- CSS Modules
- lucide-react
- react-icons

## Requisitos

- Node.js 18+
- npm ou yarn

## Instalação

```bash
npm install
```

## Execução local

```bash
npm run dev
```
